# Editing and artifact authority

`MASTER_BLUEPRINT.md` is the canonical editable specification for coders, Git history and automated analysis. `MASTER_BLUEPRINT_Readable.docx` is a generated human-readable rendition and MUST NOT be edited independently. If documents differ, Markdown wins; regenerate the Word version from the current Markdown version. The `prompts/` and CSV are implementation companions and do not override the master. No application has been implemented by this package.
