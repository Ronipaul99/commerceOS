# ADR-024 BusinessOS engineering toolchain for v3.3

**Decision** APPROVED on 24 November 2026 by Roni paul as Founder/Product and Architect. The requester confirmed the carry-forward and M01.01 POS scope in this conversation. [RG0 signoff](../RG0_SIGNOFF.md) · [Prior ADR-024](../../doc/CommerceOS_v3_1_Engineering_Development_Package/commerceos-execution-v3.1/MASTER_BLUEPRINT.md#234-adr-024-businessos-engineering-toolchain)

## Decision

Adopt the previously approved selections for the relevant v3.3 work items. Preserve the master platform baseline. Use the existing web toolchain for the independent POS shell in M01.01, with operational POS delivery governed by its own capability and release gates.

| Component | Approved choice |
|---|---|
| Business Web | Next.js + TypeScript |
| Web UI components | shadcn/ui + Radix UI + Tailwind CSS |
| Server state | TanStack Query |
| Forms | React Hook Form + Zod |
| Web local state | Zustand |
| Backend unit tests | Jest |
| Integration tests | Testcontainers + PostgreSQL |
| Browser end-to-end tests | Playwright |
| API tests | Supertest + OpenAPI contract validation |
| Load tests | k6 |
| CI/CD | GitHub Actions |
| Telemetry | OpenTelemetry |
| Database connection pooling | PgBouncer when warranted |
| Infrastructure as code | Terraform |

Adopt each selection in its owning work item. Confirm pool compatibility and measured need before adopting PgBouncer, and keep migrations on a direct connection when pooled. Fastify, authentication/OTP, payment and courier providers, hosting topology, and the telemetry collector/exporter remain open under their applicable gates. The existing Express scaffold is the M01.01 verification target. This approval resolves G-18 for the M01.01 scaffold. Later tool or provider selections retain their own approvals.

## Compatibility and evidence

The carry-forward preserves the current app boundaries and pinned scaffold dependencies. The POS shell shares public web packages and requires its own workspace importer and independent build. See the [master amendment](../../prompts/CommerceOS_v3_3_General_BusinessOS_Execution_Pack/MASTER_BLUEPRINT.md#234-adr-024-businessos-engineering-toolchain-for-v33) and [M01.01 verification](../features/M01.01/VERIFICATION.md). Rollback follows the master change protocol and removes the POS shell and its importer if the scaffold decision is withdrawn. No database migration is involved.
