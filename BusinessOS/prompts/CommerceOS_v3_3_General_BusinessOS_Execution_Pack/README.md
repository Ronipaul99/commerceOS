# CommerceOS v3.3 — Generalized Business OS · Unified Prompt Pack

**Purpose:** one comprehensive end-to-end executable prompt per verified v3.1 work item, generalized to configurable commerce-oriented businesses.

## What is in the package

- `MASTER_BLUEPRINT.md` — v3.3 generalized authoritative source (new scope and validation policy; prior v3 master retained only in archive).
- `SCOPE_AND_EVIDENCE_POLICY.md` — what general-purpose means, supported vs gated capabilities, truthful synthetic research status.
- `ENGINEERING_EXECUTION_ROADMAP.md`, `WORK_ITEMS.csv`, `MILESTONE_GATES.md` — revised source-derived execution guidance; M00/M08 no longer claim real reference merchants.
- `AGENTS.md`, `TECHNOLOGY_DECISIONS.md`, `UNIFIED_PROMPT_STANDARD.md` — coding agent rules and technology governance.
- `prompts/M00/M00.01.md` ... `prompts/MF/MF.03.md` — 123 self-contained unified work-item prompts: 120 planned Business OS and 3 future, deferred storefront items.
- `PROMPT_ATLAS.md`, `PROMPT_QUEUE.csv`, `WORK_ITEM_STATUS.csv` — sequence and evidence tracking.
- `00_START_HERE.md`, `CHANGELOG_v3_3.md`, `SOURCE_AUDIT.md`.
- `archive/` — unchanged historical v3 sources, not normative.

## Exact execution

1. Extract this package into the project repository. Do not retain an older `MASTER_BLUEPRINT.md` at an equal authority path.
2. Paste/execute `00_START_HERE.md` in Codex. It must inspect current code and identify blockers, not claim any work done.
3. Execute `prompts/M00/M00.01.md`; review document hypotheses and sign internally. Continue one file at a time, in `PROMPT_QUEUE.csv` order.
4. Each prompt runs Design → Implement/Produce → Verify (with human design stop for high risk). Human approves before merge and before advancing. Record links to real test evidence in `WORK_ITEM_STATUS.csv`.
5. Never start future `MF` work without separate authorization.

**Important:** The prompt pack is a design/execution specification, not implemented software or evidence of merchant acceptance, compliance or performance.
