# Reusable Prompt — Review After Each Stage

Review the stage just completed against its original requirements.

1. Identify implemented, incomplete and deferred requirements.
2. Run TypeScript, lint, unit tests and relevant integration tests.
3. Verify the implemented functionality in a running application.
4. For frontend changes, capture desktop and mobile screenshots and check against the approved Tiyas Jewel design reference.
5. Check that previously completed features still work.
6. Fix defects found within the current stage's scope.
7. Update docs/IMPLEMENTATION_STATUS.md.
8. Summarize the changed files, tests run, test results and remaining blockers.

Do not proceed to another stage automatically. Do not claim tests passed unless they were actually executed.
